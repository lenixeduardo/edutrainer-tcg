# EduTrainer TCG

MVP de catálogo de cartas Pokémon TCG para demonstração e validação visual.

## Prévia Vercel

https://edutrainer-tcg-preview.vercel.app

## Escopo do protótipo

- White mode com azul-marinho, azul e amarelo.
- Catálogo de 11 cartas Shiny com valores fornecidos.
- Busca, filtros, cards, detalhes e carrinho local.
- Resumo de pedido, sem envio real ou pagamento.
- Layout responsivo.

**Atenção:** condição, estoque, disponibilidade e autenticidade não foram confirmados. Os itens são demonstrativos e o checkout comercial não está habilitado.

## Arquivos

- `index.html`: versão estática autossuficiente da demonstração publicada na Vercel.
- `docs/DEPLOY.md`: notas de ambiente e próximos passos.

A aplicação completa Next.js/Supabase permanece em um pacote de implementação separado, até a migração do código e verificação do build. Não usar este protótipo como loja de produção.
