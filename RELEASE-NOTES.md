# EduTrainer TCG — MVP

- Layout oficial: white mode, azul #3D7DCA, azul-marinho #003A70 e amarelo #FFCB05.
- Catálogo: 11 cartas do usuário, Zapdos japonês dourado, demais recortes das montagens.
- Carrinho e preparação de pedido pelo WhatsApp quando configurado.
- Painel administrativo requer Supabase para operações compartilhadas.
- Demo não comprova fotos do verso, NM, disponibilidade ou pagamento.
- `preview.html` é um snapshot autônomo para referência visual com miniaturas comprimidas, não substitui a aplicação Next.js.
